Editar a escala compartilhada

Todos podem consultar a escala. Para editar, use uma conta com acesso de escrita ao repositório TadeuMartins/roge-2026-planner.

Como habilitar a edição no GitHub
  1. Abra a criação de token no GitHub.
  2. Escolha um token de acesso refinado (fine-grained), uma validade curta e somente o repositório roge-2026-planner.
  3. Em Repository permissions, habilite Contents: Read and write. Copie o token e cole abaixo.

O token é usado apenas nesta aba e não é salvo no navegador. Os nomes ficam públicos no repositório e no histórico do GitHub. Não inclua informações confidenciais.
